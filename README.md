# Prompt Block Library — расширение для SillyTavern

Расширение для переноса блоков промпта между пресетами Chat Completion. Сделано под
мобильный экран: крупные области нажатия, ничего не нужно перетаскивать пальцем.

Проверено на SillyTavern **1.18.0**.

## Что оно решает

Штатно, чтобы перенести один блок из пресета A в пресет B, нужно: открыть блок,
скопировать текст, переключить пресет, создать новый блок, вставить текст, вписать
имя, закрепить его в списке. Для нескольких блоков — повторить всё столько же раз.

С расширением: открыть окно, выбрать пресет-источник, отметить галочками нужные
блоки, отметить пресеты-получатели, нажать «Перенести». Переключать пресеты не надо
— расширение читает их все напрямую.

## Установка (Termux)

```bash
cd ~/SillyTavern/public/scripts/extensions/third-party
git clone -b claude/silly-tavern-block-transfer-wd1zqj \
    https://github.com/axioma11/rsschool-cv PromptBlockLibrary
```

Дальше — перезагрузить страницу SillyTavern в браузере (перезапускать сервер не
нужно). Расширение появится в списке `Extensions` как `PromptBlockLibrary`.

Обновление:

```bash
cd ~/SillyTavern/public/scripts/extensions/third-party/PromptBlockLibrary
git pull
```

## Как открыть

Есть три входа, все делают одно и то же:

- иконка 📖 в ряду кнопок над списком блоков промпта (там же, где импорт/экспорт/«+»);
- пункт «Библиотека блоков промпта» в меню расширений (волшебная палочка);
- команда `/prompt-library` (короткий вариант — `/pbl`) в поле ввода чата.

## Как пользоваться

**Верхний выпадающий список** — источник: вся библиотека, отдельная её папка или
любой пресет. Пресеты читаются напрямую, переключать активный пресет не нужно.
Текущий пресет помечен словом «(текущий)» и показывается вместе с несохранёнными
правками.

**Порядок блоков** — тот же, в каком они идут в промпте и уйдут в модель, то есть
как в списке блоков SillyTavern. Открепленные блоки (их нет в промпте, они живут
только в выпадающем списке) идут в конце, по алфавиту. Блоки-маркеры не
показываются, поэтому список короче, чем в самом SillyTavern.

**Галочки слева** — выбор блоков. Выбор не сбрасывается при переключении источника,
поэтому можно набрать блоки из нескольких пресетов и перенести всё одним заходом.
Счётчик «Выбрано: N» внизу. После законченного действия — переноса, добавления в
библиотеку, перемещения в папку, удаления — галочки снимаются сами, чтобы
случайно не прихватить их к следующему действию.

**«Скрыть пустые»** — прячет блоки-разделители: пустые и очень короткие (по умолчанию
короче 20 символов). Порог меняется в «⋯ → Настройки». Уже отмеченный блок не
прячется, даже если попадает под фильтр.

**Поиск** — по названию и по тексту блока.

**Шеврон справа** — развернуть текст блока, чтобы посмотреть, что берёшь.

**«В пресеты»** — перенос. Открывается список пресетов с галочками, можно отметить
сразу несколько. Блок кладётся **в начало списка и включённым** — сверху его сразу
видно и легко сдвинуть на нужное место. Если переносишь несколько блоков, они
встают сверху в том же порядке, в каком шли в источнике.

**«★ В библиотеку»** — положить отмеченные блоки в библиотеку (личное избранное,
живёт в настройках SillyTavern и не привязано к пресетам). В списке блоков промпта
у каждого блока появляется маленькая звёздочка — она кладёт блок в библиотеку в
одно нажатие. Если открыта папка, блок попадает сразу в неё.

**Версии.** Если блок с таким названием уже в библиотеке:

- полностью такой же (то же название и тот же текст) — ничего не добавляется;
- текст отличается — расширение показывает, сколько токенов в старой и в новой
  версии, и предлагает три варианта: сохранить как новый блок под именем
  `Название (v2)` (имя можно поправить), заменить копию в библиотеке новой или
  пропустить.

**Карандаш** — редактор: название, роль и текст. Работает для любого блока: и для
записи библиотеки, и для блока любого пресета. Сверху написано, что именно
правится — `★ Библиотека` или имя пресета. Поле текста занимает всё окно, так что
писать на телефоне можно и с открытой клавиатурой.

**«Обновить и остальные копии (найдено: N)»** — галочка в редакторе. Появляется
только если этот блок есть где-то ещё; если он один такой, вопрос не задаётся и
правка просто сохраняется на месте. Если галочка стоит, после сохранения
показывается список найденных копий с галочками:

- «скопирован отсюда» — копия, связанная невидимой меткой (её ставит расширение,
  когда копирует блок или когда впервые обновляет группу копий);
- «совпадает название» — блок с тем же названием, связь неизвестна.

В списке бывают и пресеты, и сама библиотека. Отмеченные копии получают текст и
настройки только что сохранённой версии; позиция в списке и вкл/выкл не трогаются.
После первого такого обновления группа получает общую метку, и дальше копии
находятся точно, а не по совпадению названия.

**Папки.** «⋯ → Новая папка», «⋯ → Переместить в папку» (можно создать папку прямо
в списке выбора), «⋯ → Переименовать папку» и «⋯ → Удалить папку» — удаление папки
блоки не трогает, они просто остаются без папки. Папки видны в верхнем списке как
`★ / Название`, плюс есть `★ / Без папки` и `★ Библиотека — все`.

Из пресета блоки кладутся в папку сразу: «⋯ → В библиотеку, в папку» — один шаг
вместо «сначала в библиотеку, потом в папку». Исходный пресет при этом не
меняется, блок именно копируется в библиотеку.

**Теги** — только для блоков библиотеки: «⋯ → Изменить теги», через запятую. Над
списком появляется строка тегов-фильтров. Теги и папки независимы: папка у блока
одна, тегов сколько угодно.

**«⋯ → Редактировать блок»** — то же, что карандаш, для единственного отмеченного
блока.

**«⋯ → Удалить из пресета»** — удаляет отмеченные блоки из пресетов. Работает
группой и сразу по нескольким пресетам: выбор блоков не сбрасывается при
переключении источника, поэтому можно отметить один и тот же мусорный блок в
трёх пресетах и снести всё за раз. Перед удалением показывается список
«пресет — блок». Встроенные блоки SillyTavern (Main Prompt, Auxiliary Prompt,
Post-History Instructions, Enhance Definitions) удалить нельзя — SillyTavern всё
равно создаёт их заново, расширение их пропускает и говорит об этом.

**«⋯»** — ещё экспорт библиотеки в JSON-файл (вместе с папками и тегами), импорт
(с выбором «добавить» или «заменить») и настройка порога «пустых» блоков.

## Что переносится вместе с блоком

Текст, роль (system / user / assistant), позиция вставки (относительная или в чат),
глубина, порядок инъекции, триггеры и флаг «запретить переопределение». Не
переносится только позиция в списке — блок всегда встаёт в начало.

Блоки-маркеры (Chat History, World Info, Char Description и прочие «кнопки» с
булавкой) в списке не показываются: вне своего пресета они ничего не значат.

## Совпадение имён

Если в пресете-получателе уже есть блок с таким же названием, перед переносом
открывается окно со списком совпадений. Имена уже подставлены с суффиксом —
`Prose Rules (2)` — их можно отредактировать или отметить «Пропустить». Существующий
блок никогда не перезаписывается.

## Что расширение дописывает в пресеты

У блоков, которые расширение копирует или обновляет группой, появляется одно
служебное поле (`pblOrigin`) — общий идентификатор группы копий. SillyTavern его не
видит и не использует, при генерации оно не отправляется: оно нужно только для
того, чтобы позже найти все копии одного блока, не полагаясь на совпадение
названий. Поле переживает сохранение и перезагрузку пресета.

## Куда сохраняется

- перенос в **неактивный** пресет — сразу в файл пресета;
- перенос в **активный** пресет — и в файл, и в живые настройки, поэтому блок
  появляется в списке промпта немедленно и не теряется при переключении пресетов;
- удаление и обновление блоков в пресетах — по тем же правилам: файл пресета плюс
  живые настройки, если пресет активен;
- библиотека, папки и теги — в настройках SillyTavern (`extension_settings`), плюс
  экспорт в JSON.

## Язык

Интерфейс сам подхватывает язык SillyTavern: русский, если выбран русский, иначе
английский.
