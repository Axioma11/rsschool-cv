# Prompt Block Library — расширение для SillyTavern

Расширение для переноса блоков промпта между пресетами Chat Completion. Сделано под
мобильный экран: крупные области нажатия, ничего не нужно перетаскивать пальцем.

Проверено на SillyTavern **1.18.0**.

## Что оно решает

Штатно, чтобы перенести один блок из пресета A в пресет B, нужно: открыть блок,
скопировать текст, переключить пресет, создать новый блок, вставить текст, вписать
имя, закрепить его в списке. Для нескольких блоков — повторить всё столько же раз.

С расширением: открыть окно, выбрать пресет-источник, отметить галочками нужные
блоки, отметить пресеты-получатели, нажать «Перенести». Переключать пресеты не надо
— расширение читает их все напрямую.

## Установка (Termux)

```bash
cd ~/SillyTavern/public/scripts/extensions/third-party
git clone -b claude/silly-tavern-block-transfer-wd1zqj \
    https://github.com/axioma11/rsschool-cv PromptBlockLibrary
```

Дальше — перезагрузить страницу SillyTavern в браузере (перезапускать сервер не
нужно). Расширение появится в списке `Extensions` как `PromptBlockLibrary`.

Обновление:

```bash
cd ~/SillyTavern/public/scripts/extensions/third-party/PromptBlockLibrary
git pull
```

## Как открыть

Есть три входа, все делают одно и то же:

- иконка 📖 в ряду кнопок над списком блоков промпта (там же, где импорт/экспорт/«+»);
- пункт «Библиотека блоков промпта» в меню расширений (волшебная палочка);
- команда `/prompt-library` (короткий вариант — `/pbl`) в поле ввода чата.

## Как пользоваться

**Верхний выпадающий список** — источник: «★ Библиотека» или любой пресет. Пресеты
читаются напрямую, переключать активный пресет не нужно. Текущий пресет помечен
словом «(текущий)» и показывается вместе с несохранёнными правками.

**Галочки слева** — выбор блоков. Выбор не сбрасывается при переключении источника,
поэтому можно набрать блоки из нескольких пресетов и перенести всё одним заходом.
Счётчик «Выбрано: N» внизу.

**«Скрыть пустые»** — прячет блоки-разделители: пустые и очень короткие (по умолчанию
короче 20 символов). Порог меняется в «⋯ → Настройки». Уже отмеченный блок не
прячется, даже если попадает под фильтр.

**Поиск** — по названию и по тексту блока.

**Шеврон справа** — развернуть текст блока, чтобы посмотреть, что берёшь.

**«В пресеты»** — перенос. Открывается список пресетов с галочками, можно отметить
сразу несколько. Блок кладётся **в конец списка и включённым**.

**«★ В библиотеку»** — положить отмеченные блоки в библиотеку (личное избранное,
живёт в настройках SillyTavern и не привязано к пресетам). В списке блоков промпта
у каждого блока появляется маленькая звёздочка — она кладёт блок в библиотеку в
одно нажатие.

**Теги** — только для блоков библиотеки: «⋯ → Изменить теги», через запятую. Над
списком появляется строка тегов-фильтров.

**«⋯»** — экспорт библиотеки в JSON-файл, импорт (с выбором «добавить» или
«заменить»), удаление из библиотеки, настройка порога «пустых» блоков.

## Что переносится вместе с блоком

Текст, роль (system / user / assistant), позиция вставки (относительная или в чат),
глубина, порядок инъекции, триггеры и флаг «запретить переопределение». Не
переносится только позиция в списке — блок всегда встаёт в конец.

Блоки-маркеры (Chat History, World Info, Char Description и прочие «кнопки» с
булавкой) в списке не показываются: вне своего пресета они ничего не значат.

## Совпадение имён

Если в пресете-получателе уже есть блок с таким же названием, перед переносом
открывается окно со списком совпадений. Имена уже подставлены с суффиксом —
`Prose Rules (2)` — их можно отредактировать или отметить «Пропустить». Существующий
блок никогда не перезаписывается.

## Куда сохраняется

- перенос в **неактивный** пресет — сразу в файл пресета;
- перенос в **активный** пресет — и в файл, и в живые настройки, поэтому блок
  появляется в списке промпта немедленно и не теряется при переключении пресетов;
- библиотека — в настройках SillyTavern (`extension_settings`), плюс экспорт в JSON.

## Язык

Интерфейс сам подхватывает язык SillyTavern: русский, если выбран русский, иначе
английский.
